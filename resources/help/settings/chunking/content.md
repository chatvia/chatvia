Each kind of content is split in its own way, based on how it is built. This card shows the way in use for each kind. You can change it under **Advanced**.

- **Markdown** — Web pages, Markdown files and ebooks.
- **Text** — Typed texts and .txt files.
- **Transcript** — The text of audio and video files.
- **Documents** — PDF, Word, slides, spreadsheets and images. Each page is one chunk and is not split further.

**Try it** tests the options on this page before you save them. Nothing is stored.

- **Split as** — The kind of content to split the text as.
- The text box holds a sample of the chosen kind. It changes when you choose another kind. You can paste your own text instead; it stays when you change the kind.
- **Split this text** — Shows the chunks and the size of each one, in tokens or characters. "View whole chunk" opens a chunk in full.

**Tip:** Paste a real page from your own sources to see how it will be split.
