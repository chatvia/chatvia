Choose which kinds of files workspaces can upload as knowledge for their agents.

- **Accepted file types** — Tick each kind you want to allow: PDF, Word, Spreadsheets, Presentations, Text and Markdown, Ebooks, Images, Audio and Video. The file endings of each kind are listed under it. At least one kind must be on. A kind you turn off is no longer offered for upload. Files that were already uploaded keep working.

Some kinds need a service from **Settings → AI models**:

- PDF, Word, Presentations and Images need a **document reader** (Mistral OCR or Azure Document Intelligence).
- Audio and Video need **speech to text**.

Without that service, those kinds are not offered, even when they are ticked here. Text, Markdown, spreadsheets and ebooks always work.

**Tip:** Turn off the kinds you do not want, so people only upload what your agents should learn from.
