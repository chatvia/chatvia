Controls who can create a new workspace, and how many agent replies a new workspace gets each month.

- **Open sign-up** — When on, anyone can create a workspace on the sign-up page (/register). When off, the sign-up page is closed.
- **Monthly message limit of new workspaces** — How many agent replies a new workspace can get each month. 0 means no limit. When a workspace reaches its limit, its agents stop replying until the next month starts. A workspace gets this limit when it signs up, so a change here does not change workspaces that already exist.

**Tip:** To change the limit of one workspace, open that workspace under **Workspaces** in the admin panel.
