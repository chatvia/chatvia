Agents can use the Perplexity tool to search the web. Each workspace adds its own Perplexity API key. Here you only set where the app reaches Perplexity, and which models it uses.

- **Address** — The address of the Perplexity service.
- **Search model** — The model behind the web search, fetch page, finance search, people search and run code tools.
- **Ask model** — The model behind the "ask" tool. It gives a full answer with reasons, from web sources.
- **Research model** — The model behind the "research" tool. It looks deeply across many sources, so it is slower.

A model name must be one that Perplexity offers.

**Tip:** Not sure? Keep the defaults. Change them only when Perplexity changes its address or its model names.
