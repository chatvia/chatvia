Sets the name and links that people see in this app, instead of Chatvia's.

- **Product name** — Shown in the app, in the browser tab and in emails. Leave it empty to use the name shown in the field.
- **Website** — The logo on the sign-in pages links here. Leave it empty to link to the sign-in page.
- **Documentation** — Adds a Documentation link to the dashboard header. Leave it empty to hide the link.
- **API documentation** — Where the API documentation links in the dashboard lead. The API is how other software talks to this app. Leave it empty to use the guide this app has at /docs/api.

**Tip:** Use full addresses that start with https://.
