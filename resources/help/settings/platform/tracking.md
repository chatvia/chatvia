The tracking code is added to every page of this app, such as the dashboard, the hosted chat and the sign-in pages. Use it to count visits with an analytics service, for example Plausible, Matomo or Google Analytics. Nothing is added while it is empty.

- **Code** — The code your analytics service gives you, usually one or more `<script>` tags. Copy it as it is. It goes into the `<head>` of each page. Leave it empty to turn tracking off.

**Tip:** The code runs only on a live (production) install, so visits to a test or development copy are never counted.

**Careful:** The code runs on every page, also for people who are signed in. Paste only code from a service you trust.
