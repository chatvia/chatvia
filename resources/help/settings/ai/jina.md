Jina can make embeddings (number codes that let the agent find text by meaning). It is used only when Embeddings is "Jina" on the Services card.

- **API key** — Get it from the Jina website. It is stored encrypted and never shown again. Leave the field blank to keep the saved key. Without a key, Jina embeddings do not work.
- **Address** — The Jina web address. Leave it blank to use the default.
- **Embedding model** — The model that makes the embeddings. Leave it blank to use the default. It is locked once sources are trained.

**Tip:** With Jina embeddings, "Automatic" reranking is off. Pick a reranker on the Services card if you want one.
