Plausible is a service that counts visits to web pages. Here it counts visits to the pages of this app, such as the dashboard and the hosted chat. You see the numbers in your Plausible account. Nothing is loaded while the domain is empty.

- **Domain** — The site name you added in your Plausible account, for example "chat.example.com". Leave it empty to turn page counting off.
- **Script address** — Where the Plausible script is loaded from. The default is Plausible's own service. Change it only if you run your own Plausible server.

**Tip:** Counting runs only on a live (production) install, so visits to a test or development copy are never counted.
