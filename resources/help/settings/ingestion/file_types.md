Choose which kinds of files workspaces can upload as knowledge for their agents.

- **Accepted file types** — Tick each kind you want to allow: PDF, Word, Spreadsheets, Presentations, Text and Markdown, Ebooks, Images, Audio and Video. The file endings of each kind are listed under it. At least one kind must be on. A kind you turn off is no longer offered for upload. Files that were already uploaded keep working.

Some kinds need a service from Settings → AI. The text in images can only be read when **Document reading** uses a service that reads images. Audio and video need a **Speech to text** service. Without one, audio and video are not offered, even when they are ticked here.

**Tip:** Turn off the kinds your setup cannot read, so people do not upload files that will fail.
