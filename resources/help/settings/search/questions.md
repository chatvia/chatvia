People often ask short follow-up questions, like "and the price?". On its own, a question like this is hard to search.

- **Rewrite questions** — Before the search, an AI step turns the message into a clear, full question. It also looks at the previous question to understand what "it" or "the price" is about. It uses the **Fast** model (Settings → AI) and adds one short model call to each message. If the call fails, the message is searched as it was written.

**Tip:** Turn it on if agents often miss answers to follow-up questions. Leave it off to save model calls.
