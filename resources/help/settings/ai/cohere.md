Cohere can make embeddings (number codes that let the agent find text by meaning) and do reranking (putting the best search results first). It is used only when you pick Cohere on the Services card.

- **API key** — Create it in the Cohere dashboard ("Open console"). It is stored encrypted and never shown again. Leave the field blank to keep the saved key. Without a key, Cohere embeddings and reranking do not work.
- **Address** — The Cohere web address. Leave it blank to use the default.
- **Embedding model** — Makes the embeddings when Embeddings is "Cohere". It is locked once sources are trained.
- **Rerank model** — Used when Reranking is "Cohere", or "Automatic" with Cohere embeddings.

**Tip:** You only need this card if you use Cohere.
