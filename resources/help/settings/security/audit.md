The security audit log is a record of important actions in each workspace: sign-ins, membership changes (who belongs to the workspace) and changes to settings.

- **Keep the security audit log** — When on, these actions are recorded, and each workspace sees its own log. When off, nothing new is recorded. Entries already saved stay until they are older than the time set to keep them.

How long entries are kept is set on the Retention & limits page.

**Tip:** Keep it on. It helps you find out what happened after a problem.
