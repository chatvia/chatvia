When someone asks an agent a question, the agent searches its sources for the parts that answer it. This card sets how that search works, and how many parts the agent gets.

- **Keyword search** — Searches by words (keyword search) as well as by meaning. This finds exact names, product codes and rare words better. You can turn it on or off at any time.
- **Search mode** — Pick **Balanced**, **More accurate** or **Faster**. "More accurate" finds the right parts more often, but takes a little longer. "Faster" answers sooner, but may miss some parts. It only matters for agents with very large sources (the note under the field gives the size). Smaller agents are always searched in full.
- **Results per question** — The most parts of the sources an agent gets for one question, from 1 to 20. With the relevance check on (the next card), an agent may get fewer.

**Tip:** Not sure? Keep the defaults. An empty field uses the default shown in it.
