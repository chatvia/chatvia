The chat models agents can use. Each agent picks one of them in its settings.

- **Add a model** — Pick a connected provider (see **Settings → AI providers**), then one of its chat models. If the provider has no model list, type the model's name.
- **Remove** — Agents can no longer pick the model. Agents that answer with it move to the model you pick. You can add it again later.
- **Default model for new agents** — New agents start with it, and the analytics assistant uses it. Existing agents keep their model. Empty means the first model on the list.

The **Can** column shows if a model can use tools and read images. Agents with tools (forms, connectors) need a model that can use tools.

**Tip:** Start with one good model that can use tools. Add more later.
