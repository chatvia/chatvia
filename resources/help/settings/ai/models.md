Pick the AI model for each job, and how much chat history it sees. The first four lists show your chat providers' models.

- **Chat** — New agents start with it, and the analytics assistant uses it. Existing agents keep their model. Empty means the first model in the list.
- **Fast** — Short, frequent tasks, like conversation titles, safety checks and translation. A small, cheap model is best.
- **Smart** — Reads your content while sources are trained, for example page summaries and tables.
- **Vision** — Describes pictures inside documents, so search can find them. Needs a model that reads images.
- **Messages of history** — How many recent messages the model sees each time it answers. More helps follow-up questions, but costs more.
- **Document summary model**, **Document analysis model** and **PDF chat model** — Model names of the Whole-PDF reading service (Services card), typed by hand. The first two summarize and sort each source. The PDF chat model answers questions about PDF files in a chat; it must read PDFs and use tools.

**Tip:** Fast, Smart and Vision use the Chat model when empty.
