The security log records sign-ins, membership changes (who belongs to a workspace), configuration changes and data changes in each workspace. Old entries are deleted once a day.

- **Days to keep the security log** — How long entries are kept. This is the normal time for every workspace. A workspace may choose fewer days, but not more.
- **Fewest days a workspace may choose** — The shortest time a workspace may set for its own log. It cannot be more than the days to keep the log. Some rules or laws ask you to keep security records for a minimum time.

**Tip:** To stop recording new entries, use the switch on the Security page (Security audit log).
