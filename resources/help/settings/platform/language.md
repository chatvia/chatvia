The language the app uses when it does not know which language a person wants.

- **Default language** — The app first uses the language a person chose. If they did not choose one, it tries the language of their browser. If the app does not offer that language, it uses this one. Agents on messaging apps (such as WhatsApp or Telegram) also use it for their short fixed messages, like "Thinking…", when the agent's Hosted Chat and Chat Widget languages are both set to automatic.

**Tip:** Pick the language that most of your people speak.
