📚 API Reference

Method Description
chatvia.open()Opens the chat window
chatvia.close()Closes the chat window
chatvia.toggle()Toggles open/close state
chatvia.isOpen()Returns boolean if open
chatvia.send(msg)Sends a message programmatically
chatvia.newChat()Starts a new chat conversation
chatvia.destroy()Destroys widget & cleans up
chatvia.on(event, fn)Subscribe to events (open, close, ready)
chatvia.off(event, fn)Unsubscribe from events
