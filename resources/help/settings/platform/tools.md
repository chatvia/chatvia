Agents can use three built-in tools: Perplexity (web search), Weather and Currency. Each workspace adds its own API key for these services. Here you only set where the app reaches each service, and which Perplexity models it uses.

- **Perplexity address** — The address of the Perplexity service.
- **Perplexity search model** — The model behind the web search, fetch page, finance search, people search and run code tools.
- **Perplexity ask model** — The model behind the "ask" tool. It gives a full answer with reasons, from web sources.
- **Perplexity research model** — The model behind the "research" tool. It looks deeply across many sources, so it is slower.
- **OpenWeather address** — The address of the OpenWeather service. The Weather tool uses it.
- **ExchangeRate-API address** — The address of the ExchangeRate-API service. The Currency tool uses it.

A model name must be one that Perplexity offers.

**Tip:** Not sure? Keep the defaults. Change them only when a service changes its address or its model names.
